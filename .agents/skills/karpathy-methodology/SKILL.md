# Karpathy-style coding methodology

- Read the surrounding code and trace how a feature is used before editing.
- Prefer the smallest implementation that solves the stated problem.
- Preserve existing user changes and avoid speculative dependencies.
- Keep data flow, security boundaries, and failure states explicit.
- Never expose credentials in browser code or logs.
- Inspect generated code and explain important limitations.
